# MeguvizRef 1.0.0

首个公开稳定版本，面向 Java 17 和 Android API 27+。

## 功能

| 模块 | 内容 | 运行时依赖 |
|---|---|---|
| `meguviz-ref-core` | 描述符、精确/结构查询、作用域、调用计划和有界缓存 | 无第三方依赖 |
| `meguviz-ref-diagnostics` | 结构化诊断、代码身份、持久化和恢复校验 | core |
| `meguviz-ref-android` | Android 平台与代码身份辅助功能 | core |

## 验证范围

发布构建通过 107 项核心合同、12 项诊断合同、5 项独立 Java/Kotlin 消费者检查、5 项旧编译客户端检查，以及 Android lint 和 R8 消费构建。

API 27、34、37 的设备功能验证用于覆盖代表性平台。构建和测试结果不代表所有设备环境均已认证，性能也不保证在所有场景优于直接反射。

## 下载与安装

[GitHub Release](https://github.com/jichuo1/MeguvizRef/releases/tag/1.0.0) 提供各模块的 JAR/AAR、源码包、POM、Gradle metadata、Maven 仓库 ZIP、发布清单和 `SHA256SUMS`。

Maven Central、GitHub 托管的 Maven 与 JitPack 均可使用，坐标和完整配置见[安装说明](https://github.com/jichuo1/MeguvizRef/blob/main/docs/installation.md)。
