# MeguvizRef 1.0.0

首个公开稳定版本，包含以下独立 Maven 模块：

| 模块 | 内容 | 生产依赖 |
|---|---|---|
| meguviz-ref-core | 描述符、精确/结构解析、CodeScope、调用计划与有界缓存 | 无 |
| meguviz-ref-diagnostics | 结构化收据、强内容身份、文件/内存存储和恢复校验 | core |
| meguviz-ref-android | Android 代码身份和平台辅助功能，API 27+ | core |

核心实现由已验收的 1.0.0-rc.1 晋升，Java 17 字节码，公开 API 保持不变。1.0.0 发布构建重新执行 107 个核心合同、12 个诊断合同、5 个 Java/Kotlin 消费者检查、5 个旧编译客户端检查，并执行 Android lint 和 R8 消费构建。

晋升前在 API 27、34、37 上完成了 18 项功能检查及分组保留的 ART 测量；实际消费者在已冻结反射使用面上完成迁移、旧依赖退出与新/旧/新回退比较。此为指定宿主、配置及设备的验证，不表示任意宿主版本、所有业务功能或所有 Android 设备均已认证。性能没有统一加速承诺。

GitHub Release 提供三个模块的二进制、源码包、POM、Gradle metadata、标准 Maven 仓库 ZIP、版本/提交/哈希清单及 SHA256SUMS。公开 Maven 使用 `io.github.jichuo1.meguviz` group；JitPack 使用 `com.github.jichuo1.MeguvizRef` group。安装示例见 README。

未包含私有消费者源码、宿主 APK、设备日志、令牌、签名密钥及工程研究包。暂无外部 Hook/DEX 桥接器；高级 MH/KSP/JNI 后端仍不在本版本范围内。
